# Open sample data and ownership

The two included CSVs are original, fictional sales and inventory examples (8 sales records and 6 inventory records), released under CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/ . They contain no actual customers, transactions or organization information. The files are independent data domains, not a real operational source.

For a richer source, extend ingestion to separately licensed Olist public e-commerce data (Kaggle), UCI Online Retail, or another vetted public dataset. Check the specific data license before redistribution. The current files give an immediately runnable, fully attributed data mesh fixture.
